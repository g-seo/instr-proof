# Security Policy

## Supported versions

Security fixes are provided for the latest published InstrProof release and the current `main` branch.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Current `main` | Yes       |
| Older releases | No        |

## Reporting a vulnerability

Do not report suspected security vulnerabilities through a public GitHub Issue.

Use GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide the affected version, reproduction steps, potential impact, and any suggested mitigation.

Do not include secrets, credentials, private repository content, or unnecessary personal information.

## What to include

Please include:

* the affected InstrProof version or commit;
* the operating system and Python version;
* the commands or repository state required to reproduce the issue;
* the expected and observed behavior;
* the potential security impact;
* minimal, non-sensitive reproduction material.

## Disclosure

Please allow time to investigate and prepare a fix before public disclosure.

Confirmed vulnerabilities will be addressed and disclosed according to their severity and impact.
